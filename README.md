## Devoir n°1 : maquettes

Les maquettes haute fidélité ont été réalisées directement en HTML et CSS : un prototype cliquable
de quatre pages (accueil, liste d'une catégorie, détail d'un article, « À propos »).

- `index.html`, `categorie.html`, `article.html`, `a-propos.html`, `style.css` : le prototype ;
  ouvrir `index.html` dans un navigateur.
- `maquettes/` : captures ordinateur (annotées, pastilles orange), tablette et smartphone, et le
  schéma d'enchaînement des pages (`wireflow.png`).
